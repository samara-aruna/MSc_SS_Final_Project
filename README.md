# 📚 Online Student Learning System

## 📌 Overview
This project is an **online student learning system** developed using **PHP**. It provides a platform for students to register, access course materials, and manage their learning experience efficiently.

## 🚀 Features

- 👤 **User Registration & Authentication**
  - Students can create and manage their accounts securely.

- 📖 **Course Access**
  - Access to various course modules through the web application.

- 💳 **Account Types**
  - **Free (Non-Payment) Accounts**
    - Limited access to course content.
  - **Premium (Payment) Accounts**
    - Full access to all course modules.
    - Ability to update and manage user profiles.
    - Access to the online library.

- 🧑‍💻 **Profile Management**
  - Premium users can update their personal information and preferences.

- 📚 **Online Library**
  - Available for premium users to enhance their learning resources.

## 🛠️ Technologies Used

- **Backend:** PHP  
- **Frontend:** HTML, CSS, JavaScript  
- **Database:** MySQL
